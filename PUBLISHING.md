# Publish on GitHub

Suggested repository name: **`the-constant-the-curve-and-a-paradox`**

Suggested description:

> A mathematical journey from a Goldbach constant to prime probability laws, complex functions, and a coprimality information paradox. PDF, LaTeX, and supporting calculations.

Suggested topics: `number-theory`, `probability`, `coprimality`, `information-theory`, `complex-analysis`, `latex`.

1. Create an empty repository under your GitHub account.
2. Put the **contents of this directory** at the repository root, so `README.md`, `paper.pdf`, and `source/` are immediately visible. Include the `.gitignore` and `.gitattributes` files when using Git.
3. The README links directly to the PDF and the source. `CITATION.cff` provides the paper citation; `LICENSE.md` explains the separate paper, script and font licenses.
4. Optionally create a release and attach `paper.pdf` plus the complete source archive. The manuscript identifies itself as the final version dated **25 September 2026**.

The repository has no Lean project or formal-verification dependency. Its mathematical proofs are in the paper. The optional Python scripts reproduce the numerical work and figures.
